# 星契 · AstralPact

一部发生在花夏星（Hosum）的动物金融寓言短剧。动物居民买卖的股票称为「星契」，故事从一场交易热潮展开，以王室、金融势力与普通家庭的命运呈现利益分配与市场博弈。

当前以第一集《负和游戏》推进制作，视觉方向为精细 **3D电影CG**。本仓库集中维护世界观、剧本、角色与场景素材、分镜关键帧及视频生成提示词。

## 本地工作台

在项目根目录运行 `npm ci` 安装依赖，再运行 `npx kacha` 启动咔嚓。已全局安装时，可直接运行 `kacha`。打开 [本地工作台](http://127.0.0.1:24074/) 查看项目设定及资产。项目文件位置见[项目目录](#项目目录)。

图片、视频和音频通过 Git LFS 直传 OSS。工作台的「全局设置 → 存储设置」填写这套媒体的 OSS 目标和本地凭据。首次克隆先用 `GIT_LFS_SKIP_SMUDGE=1` 跳过媒体下载，保存本机存储设置后再运行 `kacha lfs setup` 和 `git lfs pull`。日常更新用 `git pull` 和 `git push`。

右上角的「全局设置 → 基本信息」可修改项目名称、描述和 Logo。上传的图标以原扩展名保存到 `config/logo.{ext}`，并在 `package.json` 的 `kacha.logo` 记录当前使用的扩展名。因此更换格式时可以保留之前的图标文件。

## 制作方式

默认流程为 **阅读剧本与现有资产 → 制作关键帧 → 按反馈修订 → 编写少量连贯的视频生成段落 → 视频与后期**。关键帧数量不等于视频任务数量；即梦每段按当前项目约定不超过30秒，具体时长服从台词与动作。完整规则见 [AGENTS.md](AGENTS.md)。

各剧本目录（含片头和片尾）以 `index.md` 为默认剧本，可按需添加其他 Markdown 文件。历次修订的旧稿保存在同目录的 `archive/`，按 `v001.md`、`v002.md` 依次编号。

每集、片头和片尾的最终出片与对应的 `index.md` 放在同一目录。默认成片命名为 `index.<扩展名>`，多个交付版本可用 `index-<版本标识>.<扩展名>` 并存，例如 `index-4k.mov` 和 `index-8k.mp4`。扩展名使用文件实际格式。

本机还会看到 npm 安装的 `node_modules/`、工作台状态目录 `.kacha/`、Git 元数据目录 `.git/`，以及 macOS 生成的 `.DS_Store`。

进入制作时优先使用各资产当前版本与 README；`archive/` 中的历史稿仅按具体用途引用。目录移动后以实际路径为准，不依据旧链接恢复已移动或删除的素材。
