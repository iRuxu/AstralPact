## 连续性目标

北侧陈列柜，东侧滨海水城大窗，西侧花瓶与边柜，南侧入口。书案东西向，龙后坐南侧面向北；桌西端浑天仪、笔筒、玉碟，东端账本、两封红蜡封信件与灯具。一张书案、一张主座，灰青金龙旗、象牙白金线拱顶、青玉与黑金木作，室内暖光对应蓝紫暮色。

原图未展示的入口门、完整西墙、地面和吊灯为本轮补设计。生成图的道具朝向、柜体比例与局部装饰仍有差异；其中侧景的座椅与桌案朝向应在正式分镜中进一步校正。以原图和全景确定的空间关系为依据，不将每张图的偶然变化视为新设定。
