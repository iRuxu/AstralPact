## 空间与连续性

奶油白弧形门面、金色细窗框、粉色遮阳篷、花架与攀援花枝为本轮提案。进入店内：工作台在后中部，冷柜左侧，水槽与工具后右侧，前侧大窗在右；反打对应冷柜右、水槽左、店门前方，门外为坡道与海景。中央通道保持可走。

正反打柜体长度、工作台表面、窗洞与花架局部有生成漂移，不能视为精确三维重建。外景道路方向与海岛总图尚待统一验收；花材A窗外交易所及星环位置只作候选背景，不作为测绘关系。芭拉正式出镜时按已认可粉裙、长发编辫与正脸柔化版锁身份，开场仅背影与忙碌侧脸。

桌上星契与具体摆花动作属于后续关键帧，本轮空景未提前塞入星契或白客设备。花店名称未定。
