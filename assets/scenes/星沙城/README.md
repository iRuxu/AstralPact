# 花夏星 · 星沙城（都城）

## 场景定位与快速恢复

**正式名称：星沙城（Stardust）；所属星球：花夏星（Hosum）；城市定位：都城。** 中英文名称由用户于2026-11-19确定。目录已由用户调整为`星沙城/`。

这是星沙城的滨海都会外景资产，主基准为本目录的[滨海都会主图](index.png)，原编号为09。先看主图恢复城市身份，再按镜头需要选择视角、时间或季节参考。

**记忆要点：白金流线城市＋单组巨型直立星环与主塔＋群岛海湾和多拱桥＋山林瀑布河口。**

## 固定识别点

1. 主岛只有一组标志性的巨型直立星环与纤长主塔，白金流线基座相连；星环不能每个城区复制一座。
2. 山地森林、悬崖瀑布、蜿蜒河道和河口三角洲向群岛海湾过渡；不是纯平地城市，也不是漂浮空岛。
3. 群岛城区由细长多拱跨海桥相连，保留海水、浅滩与森林留白。
4. 建筑以象牙白和细金构件为主，曲线舒展，尖塔有等级；避免换成现代玻璃方楼或中世纪城堡。
5. 原始全景的主塔、星环、桥梁、山脊、瀑布与河道为识别依据。新机位是视觉补全，不是精确三维重建，岛屿、桥路和局部建筑仍有漂移，不能直接作为测绘地图。
6. 换季和换时间时只改变植被、雾雪、天空与照明，不允许把主要地形和地标当成可变化内容。新图尚待用户逐张确认。
