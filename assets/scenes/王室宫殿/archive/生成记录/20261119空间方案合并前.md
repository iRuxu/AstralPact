# 星沙城与王室宫殿 · 空间方案 v1

2026-11-19。本轮依据城市原图、开场01/02与用户提供的30.08秒样片整理。星沙城名称、听政用途和云雾偏好来自用户；本文件具体选址与楼翼关系为本轮设计方案，待用户验收，不表示现有图片已完成精确空间匹配。

城市统一名称为**星沙城（Stardust）**，所属星球为花夏星（Hosum）。中英文名已由用户确定；[视频地名字标](../assets/props/地名/README.md)为后期叠加素材，其新稿验收与本文件空间方案验收分别记录。

## 1. 城市骨架与宫殿选址

以[城市主基准](../assets/scenes/星沙城/09-花夏星-滨海都会.png)的画面为定位基准，不把画面左右直接当作地理东西。

- 左侧和近景：内陆山林、悬崖瀑布、河谷，向河口湿地过渡。
- 中部：河流汇入海湾，岸线、浅滩和低矮群岛之间保留大面积水域与植被。
- 中右侧主岛：唯一巨型直立星环与纤长主塔，作为独立城市地标；其功能尚未确定，不等同王室宫殿。
- 岛间连接：细长多拱跨海桥构成城市交通骨架；宫殿另设接入陆侧道路的山脚入口和沿山上行的宫道，为新增设计，现有图片未完整展示。
- **王室宫殿选址**：城市全景左侧山地靠海湾的岬角高台，落在山林瀑布带与河口海湾的交界。保持前景主要瀑布和河道，不把整片山林改成建筑；宫殿分层沿临湾山崖展开，正面俯瞰海湾、群岛和桥梁。

原城市主图没有明确绘出宫殿。本轮已新增[城市定位全景](../assets/scenes/星沙城/空间定位/01-星沙城与王室宫殿.png)，将宫殿落实到左侧山崖，保留原图作为城市身份基准。新增图为待验收设计，宫殿在远景中作了尺度简化。

## 2. 宫殿外景与听政厅

[01光入宫城](../storyboard/第一集-负和游戏/01第一场-宫殿开场/v2/01-光入宫城.png)锁宫殿沿崖展开的象牙白流线骨架、细金镂空、尖塔、层层露台和瀑布；[02暖窗之内](../storyboard/第一集-负和游戏/01第一场-宫殿开场/v2/02-暖窗之内.png)锁上层临湾大窗与龙后听取臣下汇报的主位。

**听政厅位于宫殿上层临湾正翼。** 02的高挑暖窗是它的外部识别点，窗外露台与01对应。室内是主位与来臣汇报区，保持既有龙后坐姿和官员站位，不增加书案将其改成书房。不据紧裁画面推定完整平面或门窗数量。

样片开头约0–6秒：云层遮住宫殿下部，接近后逐渐露出窗、露台、岩壁和瀑布。其价值是分层遮挡与高度感；云雾应绕过有山体支撑的建筑，不将宫殿变成浮空城。样片约12秒附近从听政状态叠化到书案背影，正式视频宜用明确剪接交代换房，避免家具和房间变形。

## 3. 理事书房的位置

**方案：同一上层宫苑中、听政厅侧后方的内廷侧翼。** 内廊连接两室，厅外侍从可退入廊道，方便宴后回书房阅账。它有独立的临湾大窗，能看见同一城市星环地标；不是02暖窗内的同一个房间。

现有书房内部约定保留：北柜、东窗、西边柜、南入口。此处“东窗”等沿用其局部平面标记；尚未建立统一城市罗盘，不强行把城市图右侧对应正东。后续总平面需校准真实朝向与看向星环的视线。

龙后与龙王在此谈论国库和军费。龙王的具体站位/座位尚需人物同框设计；现有一张主座的空景不等于已安排好两人的完整位置。

## 4. 议会厅的位置

**方案：同一王室宫殿群内，比书房低一层的临湾侧翼，沿山岬向海湾伸出。** 由内廊与楼梯连接书房，另设通往来臣候见区的入口。它不另占海湾主岛，不设成城市里另一座不相关的独立议会大楼。

保留当前室内北主位、西窗、东柜、南入口、五席布局。本方案将会议翼放在山岬另一侧的临水面，使西侧窗口仍能看到海湾支汊与群岛；书房东窗与议会厅西窗可以朝向不同水面。不能要求两室窗外出现完全相同角度和大小的星环主塔。

“低一层”是本轮建议，不是从现有图测量所得。宫殿两翼之间的真实长度、楼层标高、外窗对应及星环可见性，待总平面和定位外景验证。

## 5. 镜头路线与待验收项

城市海湾 → 岬角山崖宫殿 → 云雾间上层听政暖窗 → 明确剪接到相邻内廷书房 → 合账声接较低侧翼议会厅。

新增清晨云雾图作为天气/时段关键帧，不能据此把原剧本“夜/暮色”的整场开场自动改为清晨；若用户决定替换时段，01、02、室内窗景及后续议会厅都需统一调整。

本轮已补充城市落点全景、[宫殿三室定位总览](../assets/scenes/王室宫殿/空间定位/01-宫殿三室位置总览.png)、听政厅无人机位、书房和议会厅的外部侧翼机位。书房原有四机位、议会厅认可v2四机位继续使用；议会厅内部未重绘。

用户验收顺序：城市落点与尺度 → 宫殿外立面和云雾 → 三个房间的楼翼对应 → 议会厅内部修订。全部新图为候选，不将本轮制作完成误写成用户认可。


## 6. 本轮位置图的读法

总览图中听政厅为中央高挑暖窗，理事书房在画面右侧附属上层侧翼，议会厅在左侧较低的连续高窗侧翼。该左右关系仅对总览机位成立；原开场01为另一侧接近宫殿，不能要求山体或窗口永远处于画面同一侧。

室内的北/东/南/西是既有局部平面坐标。三个房间的局部坐标尚未统一为行星地理方位，各翼可沿曲折山崖旋转；因此书房“东窗”和议会厅“西窗”不能直接解释为在同一罗盘上相背180度。后续若制作严格总平面，再明确各房间相对城市的旋转角度与可见扇区。

定位总览含中文引线，属于制作说明图；正式影视镜头使用各场景无标注外景。生成全景在建筑体量、远处星环大小和局部桥路上仍存在美术化漂移，后续镜头需按城市主基准与本轮楼翼关系校正。
