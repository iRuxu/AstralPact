# 场景美术设定

新生成图片的统一执行规范见[3D电影CG风格与生成工作流](3D电影CG风格与生成工作流.md)，以用户认可的宫殿开场v2新版图为默认渲染基准。下文约束具体建筑与场景，不覆盖新规范的角色、材质和精度要求。

## 当前场景风格基准

场景采用**东方意象与流线型未来宫廷融合的风格化电影 CG**：象牙白建筑骨架、细金镂空、黑金家具、青玉饰面，以及室内暖光与窗外蓝紫暮色的对比。画面有可信的体积、材质和空间，保留经过美术设计的曲线与轮廓。

此前“手绘暗黑漫画线条、赛璐珞式上色、砂岩拱门”的描述不再作为宫殿场景的生成基准。角色普通立绘仍可保留原来的画风，用于锁定身份和造型；进入场景时统一受光与材质表达，不因此重新设计角色。

## 建筑连续性规则

### 形体与结构

- 以连续、舒展的象牙白曲面和拱形结构为骨架，细金线沿结构边缘收口。柱、拱和穹顶之间有明确的连接与承重关系。
- 窗洞采用主参考中的高挑流线拱形与透亮大玻璃，金色镂空集中在拱顶或窗缘，保留足够开阔的窗景。当前议会厅沿用第 18 版窗形；此前圆拱试验不自动成为定稿规则。
- 曲线必须有起止、厚度和透视逻辑，不生成交缠、融化或突然分叉的白色墙体。尤其检查书柜外侧的白色大拱与顶面连接。
- 保留东方意象：东方龙、云纹、玉石、礼制轴线；不依靠堆叠斗拱、传统灯笼或宫庙符号来表达东方感。
- 同一房间换机位时保持窗数、柱网、门洞、家具尺寸、旗帜位置和柜体分格一致，不能把反打当成另一间相似房间重新设计。

### 材质与配色

| 部位 | 固定方向 |
| --- | --- |
| 建筑主体 | 象牙白、暖白的石材或珍珠质感复合材质；细微纹理与柔和高光，避免塑料感。 |
| 金属 | 暖金、香槟金的细边、镂空和雕饰，反射有层次；避免所有边线都像霓虹灯发光。 |
| 家具与木作 | 深色木材、黑色石质桌面、深色皮革，搭配精细金纹与少量玉饰。 |
| 玉石 | 青玉、深青绿，用于星图墙、细长柜体饰板和局部嵌饰，带淡淡矿物纹理。 |
| 外部环境 | 深蓝至蓝紫星空、暮色水面、少量日落暖色和城市灯光，与室内形成冷暖对比。 |

采用主参考的明亮黑金青玉方向。后续低饱和冷黑金、灰暗调色和均匀提亮的试验不作为默认目标。金属、石材、皮革、织物分别体现自身的粗糙度与反射，避免全场同一种镜面。

### 灯光与画面质感

- 暖光来自室内灯具和建筑照明，冷色来自窗外天空与水面；两者同时作用于建筑和角色。
- 室内明亮可读，保留柱间、柜内及人物侧面的阴影层次。权力感来自尺度、轴线、主位与明暗秩序，不以整体欠曝制造压迫感。
- 暖金高光可以丰富，但不能把白色建筑整体染成橙色。暗色角色也需保留面部、服装及毛发细节。
- 使用风格化三维电影质感、柔和体积与自然接触阴影；不加粗黑漫画轮廓线，不切回平面赛璐珞分块。

## 议会厅固定设计

- 长方形黑金长桌，远端为龙王主位，长边各两席，共五张座椅；三头犬在龙王近侧地面站立，不占座、不站桌面。
- 以入口看向主位：左侧为窗和水城景观，右侧为陈列书柜；未央左远、八爪左近、鳄王右远、狼王右近。
- 右侧书柜为**宽深色陈列格与窄青玉饰板交替**，柜内放卷宗、匣盒和玉石摆件。保持宽窄节奏与连续外拱，不改成等宽三拱门，不把白色斜梁穿过柜面。
- 当前版本保留黑底金色东方龙旗、开放式环形镂空吊灯及细长垂饰，均按第 18 版图执行。龙后书房的灰青旗可属于另一室内变体，不自动替换本厅旗帜。
- 当前桌面保留星轨金线与近端花纹，以第 18 版为准；先前去花、简线版本保留为试验，不视为当前定稿。

### 星图墙与十二星座动态设定

主位背后为嵌入墙面的青玉圆形星图，带金色外框、淡星云/矿物底纹、细金连线与少量星芒。当前静帧显示金牛座；它是十二星座中的一个显示状态，不是永久固定的墙徽。

**后续计划：星图可动态变化，切换十二星座。** 保持圆框、青玉底材和空间位置稳定，只改变圆盘内的星点、连线及适量微光，不重新生成整面墙或改变房间灯光。

- 星座内容包括白羊、金牛、双子、巨蟹、狮子、处女、天秤、天蝎、射手、摩羯、水瓶、双鱼。
- 每种星座应使用可辨识的星图结构；正式制作时逐张核对星位与连线，不能用随机装饰线代替。
- 默认以星点和细线表现，不改成具象动物浮雕、巨大星座符号、中央金球或浑天仪。
- 建议先制作同构图的十二种墙画状态，再做星点渐亮、旧线淡出、新线浮现等克制过渡；这是制作建议，切换顺序、节奏和时长尚未确定。
- 当前交付为静态金牛座场景图，十二种状态与动态效果尚未制作。

## 后续生成与检查

1. 先确定主参考与目标机位。新房间引用宫殿内外两张图；议会厅新镜头还必须引用第 18 版或后续明确认可的结构图。
2. 分开注明参考用途：场景图约束建筑与灯光，角色图约束物种、头型、服装与配饰；模型不会自动保证二者都一致。
3. 一次只改明确提出的部位。局部精修继续附主参考，避免不断引用上一张改图导致建筑与配色逐轮漂移。
4. 检查拱线和墙体连接、书柜宽窄分格、窗景城市、座位数量、旗帜与灯具，以及冷暖光是否连贯。
5. 新结果另存版本，不覆盖基准图。记录提示词与实际像素尺寸，不能把提示词里的“4K”当成实际输出规格。

## 花夏星都城 · 星沙城

花夏星的都城正式名为**星沙城**（2026-11-19用户确定），对应现有“花夏星-滨海都会”场景资产。当前城市面貌以[滨海都会原图](../assets/scenes/星沙城/09-花夏星-滨海都会.png)为主基准；其余早期城市概念保留作探索，不混用为同一城市的已确认形态。

多视角、清晨/正午/黄昏/深夜与春夏秋冬试作见[滨海都会素材与连续性说明](../assets/scenes/星沙城/README.md)。新增十张图为候选，四季先按温和滨海气候表达，尚待确认。

- **城市固定形态**：一组巨型直立星环与纤长主塔、白金流线建筑、群岛城区与多拱跨海桥、山林悬崖瀑布汇入河口海湾。保持主地标的轮廓、层级与地形关系，不能每换镜头重新造城。
- **与宫殿衔接**：白金曲面骨架、精细金属构件和开阔水景共同构成同一文明的视觉语言；宫殿窗景应引用城市基准并按机位裁取，不随机更换城市。
- **季节与时间独立**：时间变化主要调整天空、光向、色温与城市灯光；季节变化主要调整植被、雾雪与水文表现，保留建筑和岸线。同机位试作便于对照，但生成结果仍需校正局部漂移。
- **不扩展未定设定**：星环建筑的用途、宫殿精确坐标和气候制度尚未确定；城市英文名已确定为 **Stardust**，不据名称补写未定的城市历史或地标用途。
