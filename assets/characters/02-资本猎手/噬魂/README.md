# 噬魂 · 汪汪队（三头犬）

## 身份与背景

王室猎手，与狼队同属全资国有背景的猎手。三头犬守在龙王近侧；“噬魂”是负责发言的中间头，当前素材目录以噬魂命名，不能据此拆成三个独立犬身。第一集议会中提出借助央行拨款、证券交易与财政分配榨取市场财富的计划。

依据：[世界观与角色](../../../../docs/story/世界观与角色.md)、[角色美术设定](../../../../docs/art/角色美术.md)、[第一集剧本](../../../../scripts/第一集-负和游戏/剧本.md)。

## 固定造型与表演

- 一具黑色四足犬身、三颗头、六只尖耳；琥珀眼，黑色层次毛发，中央头额部细疤，皮革项圈、铜钉与方形星纹吊牌。
- 三头分别呈现警惕、暴怒与窃笑；暴怒是中间头既有造型状态，并非每个镜头都要咆哮。议事时可收敛为自信阴狠的表情，只有中间头开口，侧头保持闭口和独立神态。
- 站在龙王近侧地面，不新增座椅，不站桌面，不改成人形西装角色；本次特写不新增人形手或手指。
- 原剧本存在“用指尖在纸上划一道”等与四足造型冲突的动作，后续制作相关镜头时需另行协调，不能据此擅自长出人手。本次未改写剧本。
