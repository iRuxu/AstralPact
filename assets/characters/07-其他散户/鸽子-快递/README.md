# 哒哒

## 角色设定

- **姓名／别名**：哒哒；原以“鸽子”称呼。
- **物种与年龄方向**：拟人鸽子，成年劳动者形象，具体年龄未定。
- **职业／定位**：快递员，代表送快递的底层劳动人民；归属其他散户角色组。具体雇主、阵营关系未定；第二集第八场作为熊大笑劝阻的白鸽快递员登场。
- **固定外形**：白色羽毛、浅色喙与鼻瘤；面部以第二集第八场白鸽版为准；保留羽翼、尾羽和有鳞鸟爪，不改成人手。
- **正式服装与装备**：旧白骑行头盔及下颌带、砖红短款反光配送工装、深灰工装裤；红色配送背箱、外绑纸箱、水瓶、腰挂扫码终端和运单袋。服装有日常磨损与小修补。
- **默认表情**：普通、自然平和，保留自然眉部表情，不再沿用灰鸽版深灰眉羽要求；不恢复早期锐利眉眼或上一轮过于委屈、可怜的神态。
