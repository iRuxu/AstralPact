# 世界观与角色

## 狐狸父子补充（2026-11-21）

**富海的命名寓意**：用户明确“富海”谐音“胡亥”，借“秦二世而亡”的意象，暗示败家子的意味。此为创作隐喻，家庭最终结局及与历史人物对应的其他情节并未因此确定。

用户构思的中产家庭父子：儿子在大学用父亲给的生活费买光之星契，盈利后自负并辍学，亏损后回家告知父亲，被骂“蠢货”。父亲是久经沙场、精明奸诈的老狐狸，用户已明确其属于空头势力，以和雷霆（电鳗）同款的闪电领章标识；儿子阵营未定。父亲正式名为**富国**，儿子正式名为**富海**（2026-11-21用户命名）；父亲职业、与雷霆的具体关系未定。用户已于2026-11-21确认父子v5造型；独立角色资料与双版本三视图入口：[富国](../assets/characters/07-其他散户/狐狸父子/富国/README.md)、[富海](../assets/characters/07-其他散户/狐狸父子/富海/README.md)。

故事发生在遥远星系中的花夏星。花夏是「华夏」的同音改写，暗指中国。Hosum 是花夏的英文名，其中 sum 有 summer 的联想。星球上的居民都是动物。它们买卖的股票叫「星契」，故事从一场星契交易热潮展开。

### 片头中的星域呈现

在浩瀚星海与星云中，三颗星先以较大、较亮的远方光点出现，并分别标出中文与英文名；镜头随后选定花夏星，靠近后才展现蓝绿色星球、山川海洋与滨海都会。

三颗星在同一画面的排列是片头的美术化星域示意，尚不构成精确宇宙地图，也不确定它们的实际距离、尺寸、恒星系统与航行时间。片头中不同的光色仅供辨认，不代表阵营善恶或力量排名。
