# 第六场 · 城市行情屏至交易所会议室 · 日

2026-11-22：按用户要求将原第6、7部分合并为一场，全部对白逐字保留。8张关键帧已生成并检查，新调度待用户审阅；未生成视频。

## 空间与表演

沿用第二场五席会议室。以南入口向北主位看：狼王北端主位，中信左远、银河右远，豹拉左近、古格预留右近空席；华泰站西侧后方、国泰海通站东侧后方。此具体座次是本轮调度提案。总共五把椅子，古格入场前六人，入场后七人，不增座、不把站立小狼漏掉。西墙行情屏，东侧临湾窗，北墙紫晶八芒星，不加宫殿青玉星座图。

古格采用已认可缩小后的颈饰比例；“大红宝石接住灯光”以切面反光表现，不重新放大。方案为一份纸质宣传方案，由豹拉放到桌上后留在原位，不变成终端或机器。古格走到空椅旁应答，剧本未要求落座，不额外加坐下动作。入口反打涉及明显转向，需以场景南门反打参考核对，不仅依靠入口轴线图推演。

## 关键帧与剪接

| 镜号 | 作用、动作和参考用途 |
| --- | --- |
| 01-街头高位横盘 | 从第五场空中投影曲线作形状匹配硬切；街头同屏下方曲线高位趋平，动物仍讨论飞船，成交音零星。行情屏与街景同框，轻推即可，不另切无参考特写。狼王“豹拉兄……”声音先入，称呼只说一次。 |
| 02-第二轮会议全景 | 交代五席、四坐两站一空席。狼王向豹拉开始询问，小狼盯西墙数字。由街头直接剪入，不合报表、不打开终端。 |
| 03-狼王担忧残局 | 狼王中近景，微皱眉摊掌向左近豹拉说完整长句；全景接近景不重起台词。 |
| 04-豹拉推来新方案 | 豹拉中景，从容把新方案放到桌面，连续说完三个题材；不插机器幻想镜头打断表演。此帧为放下动作终点，视频从手持方案自然放下，不能瞬现。 |
| 05-狼王质疑可信度 | 狼王更紧近景，略前倾、抬眉，表演区别于摊手求助。 |
| 06-豹拉示意门口 | 豹拉转头看南入口，轻示意，方案仍留在桌上。 |
| 07-古格开门入场 | 入口反打，门打开后古格迈入，宝石自然反光；小狼转头，狼王离座起身迎一步在已建立全景机位中完成，随后切此入口镜头。不得让狼王瞬移到门边。 |
| 08-古格应下财富效应 | 古格抵达右近空椅旁，先看桌面方案，再看对侧豹拉；豹拉的财富效应一句可画外落在此镜头上，古格直接答应，不加发呆停顿。 |

## 对白与段落建议

按原句自然速度暂分三段，待实配音校准；不是一图一任务，每段不超过30秒。

1. 27秒，01–04：横盘与画外称呼 → 狼王完整长句 → 豹拉放方案及完整三个题材。若实配音超过27秒，将在狼王句末分段，不能加速。
2. 18秒，05–07：狼王质疑 → 豹拉邀客 → 开门、众狼反应、狼王起身迎一步及“古格女士……”。
3. 12秒，08（辅以02空间、04方案）：古格看方案走向空椅，豹拉提出财富效应，古格“包在我身上。”，保持画面可见硬切下一场舞台，不淡出。

以上57秒是初步表演估计。关键帧审阅修订后，交付正式逐时段即梦提示词；当前不把制作方案记作用户认可，也不提交视频任务。
