## 连续性约束

1. **光束唯一。** 卡片在 02 完成化光后不再重新出现；金白核心、短幻彩尾迹始终一致。其他星点不带同样拖尾。
2. **星图稳定。** 04 建议 Hosum 在画面中下部偏中央，Asocan 左上、Dreekii 右上。构图位置是本版分镜安排，非正式宇宙地图。锁定 Hosum 后镜头沿它推进，避免切错星球。
3. **标签可读。** 每组中文在上、英文在下，用短细引线指向星点；标签避开航线与高亮星云。三组大小一致，不用大范围扫描框。
4. **城市唯一地标。** 主岛只有一组巨型直立星环与纤长主塔。保持山地森林、悬崖瀑布、河口、群岛、细长多拱跨海桥，不生成重复星环或悬空岛。
5. **光照连贯。** 云下到城市使用同一套蓝紫暮色、暖金夕光，进入城市后不突然切成正午。天空为既有美术表达，不新增天体运行设定。
6. **运动有收放。** 03–04 是寻找与辨认；05–06 加速；07 逐渐减速。默认前进方向朝画面深处，遮挡接镜后也不突然反向。

## 实施顺序

1. 先做 01 卡片、04 三星星图、07 城市终帧三个构图基准，确定统一色调与留字空间。
2. 以三组基准拆出 02–06 所需首尾帧。每段输出无字画面；剧名字标、星名与集标题全部后期叠加。
3. 先试拍 04→05「认出花夏并冲向它」和 06→07「山川入海进城」两处衔接，再补全其余段落。
4. 合成统一金白光束、字标鎏光和字幕跟踪。锁定画面剪辑后配乐与混音，输出共用母版及第一集标题版。

## 交付检查

- 卡片先于片名显现，片名有约两秒清晰阅读时间。
- 星空有寻找过程，三组星名有至少两秒完整共存时间；英文拼写为 Hosum / Asocan / Dreekii。
- 镜头明确进入 Hosum，并完整经历山川、河流、海湾与城市。
- 城市星环、主塔不复制；片头不提前进入宫殿剧情。
- 城市之后先黑场，再出「负和游戏 / Negative-Sum Game」，中文在上。
- 正片采用 v2 后，需要处理原剧本议会段后的重复集标题，详见脚本衔接说明。
